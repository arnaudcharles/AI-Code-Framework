# CONTRIBUTING.md

## Workflow

1. Open a focused branch.
2. Keep changes small and reviewable.
3. Run lint and test locally before PR.
4. Include release notes impact.

## Pull request requirements

- Describe behavior change and compatibility impact.
- Link test evidence for affected paths.
- Document security impact when applicable.
- Update metadata/changelog when releasing.

## Review policy

Review order:
1. correctness and regressions
2. security impact
3. compatibility impact
4. maintainability
