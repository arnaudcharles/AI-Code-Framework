# Puppet Module Template

Starter template for a secure and maintainable Puppet module.

## Includes

- class and defined type scaffold
- EPP template and managed file structure
- Hiera baseline
- metadata and dependency placeholders
- rspec-puppet tests
- lint and release helpers
- canonical AI instruction model using agent.md

## Quick start

1. Replace placeholder names in metadata.json and manifests.
2. Install Ruby dependencies: bundle install.
3. Run checks: bundle exec rake test.
4. Adapt CI files generated from CI.md + Generate-CI.md.
